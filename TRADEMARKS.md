## How AIDC Studio uses vendor names

- **Names and public specifications only.** The catalog cites product names with factual values (power, dimensions, flow rates, port counts) taken from public datasheets and announcements. Every value carries a source tag (`public-spec`, `announced`, `estimate`, …).
- **No vendor logos, product photos, card art, HMI screens or trade dress.** The 3D and 2D models are generic parametric shapes designed for AIDC Studio. A model labelled, for example, "GB300 NVL72-class rack" or "Helios-class rack" is a generic representation of the published dimensions. The vendor did not produce, review or endorse it.
- **No vendor documents.** Slides, manuals, videos and other vendor material are not included or redistributed. Where a planning rule follows a published reference design, the code cites the public document by title.
- **No implied endorsement.** Layout templates and sample projects use generic names. A name such as "NVL72 scalable unit" describes the equipment class. It does not mean the vendor certified the layout.
