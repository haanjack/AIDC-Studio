# AIDC Studio — Godot 4 viewer

Godot 4.4+ project (verified headless with Godot 4.7.2) that renders AIDC Studio layout exports.

## Use

1. In AIDC Studio choose **Export ▸ Godot** (or `GET /api/projects/<id>/export/godot`). The zip contains this
   project plus `layout.json`, a pre-built `scene.tscn` and the converted `models/*.glb`.
2. Open the folder in the Godot editor (first open imports the GLB models) and press **Play**.

Command-line (user args after `--`):

```bash
godot --path aidc-godot                                   # windowed viewer
godot --path aidc-godot -- --layout=/abs/path/layout.json --labels
godot --path aidc-godot -- --scene=res://scene.tscn       # instance the pre-built scene instead
godot --headless --path aidc-godot --import               # import models only (CI)
godot --headless --path aidc-godot -- --quit-after-load   # smoke test
```

Controls: LMB orbit · RMB/MMB pan · wheel zoom · WASD move · UI toggles for containment, labels, ceiling.

## How it maps the data

- `layout.json` (`aidc.layout/1`, see `packages/core/src/export/SCHEMA.md`) provides `transform.yUp` for every
  equipment item: position of the footprint center at the base and `rotationYDeg`.
- Models follow the glTF convention (front faces -Z, base at y=0), so they are placed without correction.
- Items without a GLB get a `BoxMesh` sized to catalog dims with the catalog color.
- `scene.tscn` is generated by `exportGodotScene()` and is equivalent to what the loader builds at runtime.
