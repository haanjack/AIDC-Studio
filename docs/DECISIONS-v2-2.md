## A. 1차 피드백 반영

| # | 피드백 | 결정 · 구현 지침 |

## B. 2차 범위 (DECISIONS-v2 #16의 2차 + 위 피드백)

- 전력 플레인: 3D 전력 경로(버스웨이 A/B·탭오프·RPP·피더), 단선도 ↔ 3D 연동, 시나리오(유틸리티 상실·발전기 고장·RPP 고장·부하 %), Max-Q 묶인 전력 모델.
- 냉각 토폴로지 비교: 갤러리 팬월 / 둘레 CRAH / in-row / 사이드카 / RDHx — 결정론적 비교표 + CFD-lite(가능한 옵션부터).
- 네트워크 산출물: 포트 단위 케이블 스케줄(TIA-606 라벨), IP map(/31 p2p + eBGP unnumbered, OOB/인밴드 VLAN), NOS 설정 템플릿(SONiC · Cumulus/NVUE · Arista EOS · Cisco NX-OS · Dell OS10 · Juniper JunOS; IB는 파티션/UFM 메모), 시험 코드(패브릭·η 측정 키트·노드·스토리지·전력/열, 인수 체크리스트).
- vLLM Q&A: 설치된 호스트의 서비스로 제공(`LLM_BASE_URL`/`LLM_MODEL`/`LLM_API_KEY`), 용어집·현재 분석·내장 문서 근거 답변, LLM 없으면 용어집 폴백; standalone 배포 방식 검토 문서.
- 협업(최소): 링크 공유 · 저장 버전 이력 + 두 버전 분석 비교 · 프로젝트 락(표시 이름 기반, 계정 없음).
- UI i18n: UI 언어(EN/KO) 전환 인프라 + 전 패널 문자열 사전화. UI 기본 언어는 브라우저 언어, 산출물 기본은 EN(기존 결정 유지).

## E. DU 템플릿 ↔ 컴퓨트 플랫폼 (2026-09-15)

사용자: "DU 디자인만 들어오게 할 일은 아니고, DU template에 연관된 GPU platform만 보이는 게 맞다. … Rubin에 Groq 3 LPX가 함께 들어가는 것처럼 AMD도 다른 NPU와 함께 DU를 구성할 수 있으니 이런 건 DU Template에 맡기고, 구체적인 Compute platform은 지금 체계로 하되 DU Template에 등록된 Compute platform 리스트만 보이게." 또 "AMD에서는 HGX를 UBB8이라고 부른다."

| # | 결정 · 구현 지침 |
|---|---|
| E1 | "GPU 플랫폼" → **"컴퓨트 플랫폼"**. 현재 체계(DU 템플릿 선택 + 플랫폼 선택)는 유지. |
| E2 | DU 템플릿이 **컴퓨트 슬롯**을 가진다: `computeSlots: [{ id, role: 'primary' \| 'accelerator', label, platforms: catalogId[] (등록 목록), defaultPlatform, perDu (랙 수 또는 비율) }]`. 배치 패널은 슬롯마다 선택 상자를 보여주고, **그 슬롯에 등록된 플랫폼만** 나열. NVIDIA 시설 SU는 공개 정의(Compute HAC + Support HAC)와 250 MW / 96 SU 예시를 별도 `referenceUnit`으로 보존하고, 이종 가속기는 비율 근거가 있는 경우에만 전용 슬롯으로 둔다. 범용 Custom DU는 GPU/NPU 랙과 선택적 NPU 슬롯을 제공한다. |
| E3 | 템플릿 그룹은 vendor가 아니라 물리 인터페이스 기준으로 구성한다: Standard(ORv3 HPR·ORW·EIA air/liquid) · Vendor sample(인용된 NVIDIA 시설 SU와 명시적 추정 DU/row) · Custom. Helios는 ORW 플랫폼 인스턴스이고 MI3xx/HGX/NPU는 호환되는 표준 또는 Custom 템플릿에 등록한다. Scale-up 도메인, vendor RA의 SU, 사용자 정의 홀 DU는 서로 독립된 단위다. |
| E4 | 용어: 8-GPU 베이스보드 노드는 공급사 중립 **"HGX / UBB8"** 표기(NVIDIA HGX, AMD UBB 2.0), AMD 카탈로그 항목과 템플릿 라벨에 반영. |
| E5 | 등록되지 않은 플랫폼을 쓰는 기존 프로젝트는 그대로 동작하되 경고 + "템플릿에 등록" 제안. 상면 맞춤(fit) 후보는 템플릿 × 등록 플랫폼만 열거. |
